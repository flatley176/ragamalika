# Kalamposer

A React app for composing and arranging Carnatic kalpanaswara sequences. Build multi-sequence projects, set play ranges and tempo, and preview with SoundFont playback.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Project files are JSON (`.json`) containing sequences and optional project-wide settings (tempo override, default octave).
